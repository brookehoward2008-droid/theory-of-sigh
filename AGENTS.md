# Project Instructions

Everything is fact checked before it is treated as final. Keep the tone Brooke-aligned, neural-learning informed, and ADHD-friendly: short sections, clear labels, no invented certainty.

## Publication QA Gate

For this magazine, do not call work complete until preflight and visual layout checks have run.

Required checks before final handoff:

- Run the automated tests.
- Run an HTML/source preflight for TOC links, citation anchors, 64 plate captions, and 64 source-register entries.
- Open the local preview in the browser and visually inspect the layout for caption crowding, cropped text, broken image rhythm, bad gutters, and old school/process wording.
- When working in InDesign, run InDesign preflight for missing links, overset text, bleed, color space, and fonts before export.
- When a PDF exists, visually inspect exported pages for trim, bleed, gutters, folios, captions, full-bleed image spreads, and backmatter readability.
- Do not leave original filenames, rights notes, or source traces under front-of-book images; keep those details in the backmatter source register.

If a tool can visually inspect the layout, use it before finalizing: browser screenshot/DOM checks for the web proof, PDF render checks for exported PDFs, and InDesign preflight for the `.indd`.
